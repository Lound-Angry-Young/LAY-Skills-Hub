name: routing-context-skills
description: >
  Routes context, prompt and planning requests to the matching skill: session discovery, context engineering, prompt and message compression, RTK context pipelines, knowledge graphs, requirement interviews, task breakdown, idea refinement and LAY ecosystem orchestration. Use this skill when: deciding which context or planning skill applies. Do NOT use this skill when: the task is code implementation, testing or delivery.
