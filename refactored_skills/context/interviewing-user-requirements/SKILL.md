name: interviewing-user-requirements
description: >
  Extracts what the user actually wants through a one-question-at-a-time interview until intent is about 95% clear, when a request is underspecified or the user asks to be interviewed or challenged. Use this skill when: an ask is underspecified (for whom or why now is missing), or the user asks to be interviewed, grilled or to stress-test a plan. Do NOT use this skill when: the requirements are already explicit and only need to be broken into tasks (use breaking-down-task-plans).
