name: routing-omniroute-skills
description: >
  Routes OmniRoute requests to the matching skill: inference, providers, combos and routing strategies, CLI operations, usage and cost analytics, budgets, resilience, MCP, A2A, webhooks, tunnels, network proxies, models and skill import. Use this skill when: deciding which OmniRoute skill applies to a request. Do NOT use this skill when: the task is application code unrelated to OmniRoute (use engineering or frontend skills).
