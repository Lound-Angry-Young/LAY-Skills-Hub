---
name: routing-engineering-skills
description: >
  Routes engineering requests to the matching skill: API and interface design, specifications, incremental implementation, code review and minimalism, debugging, error recovery, migrations, deprecations, performance, observability, technical debt and project constraints. Use this skill when: deciding which engineering skill applies to a request. Do NOT use this skill when: the task is frontend UI work (use routing-frontend-skills) or delivery and infrastructure (use devops skills).
---
