name: routing-qa-skills
description: >
  Routes testing and quality requests to the matching skill: test-driven development, browser automation and DevTools inspection, model benchmarks, codebase quality scans, CI repairs and pull request gates. Use this skill when: deciding which testing or quality skill applies. Do NOT use this skill when: the task is writing feature code without tests (use engineering or frontend skills).

## Domain Skills Catalog
| Skill | Finalidade Primária | Link Direto |
|---|---|---|
| [automating-browser-tests](./automating-browser-tests/SKILL.md) | Automates browser interactions, tests web pages and works with Playwright tests from the Playwright CLI | `./automating-browser-tests/SKILL.md` |
| [driving-test-driven-development](./driving-test-driven-development/SKILL.md) | Drives development with tests in a red-green-refactor loop when implementing logic, fixing a bug or changing behavior, to prove that the code works | `./driving-test-driven-development/SKILL.md` |
| [enforcing-green-pull-requests](./enforcing-green-pull-requests/SKILL.md) | Inspects and prepares the selected pull request queue against its exact current base, repairs authorized defects with contributor credit and reports full versus partial validation | `./enforcing-green-pull-requests/SKILL.md` |
| [evaluating-model-benchmarks](./evaluating-model-benchmarks/SKILL.md) | Creates and runs evaluation suites, watches live benchmark progress, views scorecards, compares model performance and integrates eval runs with CI workflows from the CLI | `./evaluating-model-benchmarks/SKILL.md` |
| [scanning-codebase-quality](./scanning-codebase-quality/SKILL.md) | Runs a scoped, read-only quality scan that reports exact-candidate evidence, failures and frozen debt, for ad-hoc gate sweeps or release preparation | `./scanning-codebase-quality/SKILL.md` |
| [sweeping-failing-ci-builds](./sweeping-failing-ci-builds/SKILL.md) | Repairs confirmed CI failures base-first, then prepares the affected pull requests one at a time with exact-candidate evidence | `./sweeping-failing-ci-builds/SKILL.md` |
| [testing-in-browser-with-devtools](./testing-in-browser-with-devtools/SKILL.md) | Tests in real browsers through Chrome DevTools MCP: inspects the DOM, captures console errors, analyzes network requests, profiles performance and verifies visual output with runtime data | `./testing-in-browser-with-devtools/SKILL.md` |
| [validating-green-release-gates](./validating-green-release-gates/SKILL.md) | Runs or inspects the local Release-Green observer for an exact base or combined pull request candidate, separating hard failures, advisory drift and incomplete evidence | `./validating-green-release-gates/SKILL.md` |
| [verifying-animated-component-compliance](./verifying-animated-component-compliance/SKILL.md) | Verifies a copied or generated animated UI component against the project rules: local imports resolved, use client where hooks are used, reduced-motion handling present, at most one WebGL component per route, touch fallback for pointer-only effects, debug controls removed, license notice kept, and the project type-checks and builds | `./verifying-animated-component-compliance/SKILL.md` |
