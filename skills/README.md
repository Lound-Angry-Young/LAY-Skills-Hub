# Skills públicas da base

Este diretório contém as ferramentas abertas de orquestração, comunicação, diagnóstico técnico e guias de repertório criativo mantidas para novos projetos.

## Skills públicas disponíveis

- **[lay-orchestrator](lay-orchestrator/SKILL.md)**: Coordena o repertório, guia a seleção por área e orquestra o diagnóstico inicial.
- **[caveman](caveman/SKILL.md)**: Protocolo de comunicação concisa e ultra-comprimida (MIT / Julius Brussee).
- **[graphify](graphify/SKILL.md)**: Grafo de conhecimento de arquitetura e código (MIT / Safi Shamsi).
- **[blender-mcp-setup-and-automation](blender-mcp-setup-and-automation/SKILL.md)**: Protocolo de detecção, instalação do Blender via Winget e automação MCP 3D.
- **[hardware-aware-render-optimization](hardware-aware-render-optimization/SKILL.md)**: Diagnóstico de GPU/VRAM para calibração de processamento gráfico local.
- **[creative-libraries-hub](creative-libraries-hub/SKILL.md)**: Guia e curadoria de bibliotecas criativas (Jakubantalik/Libraries.dev).
- **[design-reference](design-reference/SKILL.md)**: Guia de arquitetura visual e design systems de referência (voltagent/awesome-design-md).
- **[generative-ai-reference](generative-ai-reference/SKILL.md)**: Guia e padrões de IA generativa (anil-matcha/open-generative-ai).
- **[lenis-smooth-scroll](lenis-smooth-scroll/SKILL.md)**: Guia de rolagem inercial suave (darkroomengineering/lenis).
- **[react-bits-animations](react-bits-animations/SKILL.md)**: Guia de componentes animados modernos (DavidHDev/react-bits).
- **[vanta-backgrounds](vanta-backgrounds/SKILL.md)**: Guia de fundos 3D interativos WebGL (tengbao/vanta).

> As habilidades proprietárias de identidade visual e estética da LAY® estão isoladas e protegidas em cofre privado fora da distribuição pública.
