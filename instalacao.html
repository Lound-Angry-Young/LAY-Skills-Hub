01 · PRÉ-REQUISITOS

O que você precisa

Três coisas. Nada é instalado via pip: o instalador usa só a biblioteca padrão do Python.

REQ 01
Git

Para clonar o repositório com as fontes fixadas (submódulos).

REQ 02
Python 3.10+

Use python. No Windows, se não funcionar, use py -3.

REQ 03
Claude Code

CLI no terminal ou app desktop. Os subagentes aparecem nas sessões novas.

02 · INSTALAR

Três comandos

Execute no terminal, dentro da pasta do repositório clonado.

PASSO 01
Clonar com submódulos

Faça uma vez. Se já clonou sem submódulos, rode git submodule update --init --recursive.

bash · pasta de sua escolha 
git clone --recurse-submodules https://github.com/Lound-Angry-Young/LAY-Skills-Hub.git
cd LAY-Skills-Hub
PASSO 02
Instalar os subagentes

Instala os 11 arquivos lay-*.md em ~/.claude/agents/ e grava o índice de roteamento no ~/.claude/CLAUDE.md, entre os marcadores LAY-SKILLS.

Quer também Codex e Antigravity? Troque claude por all.

bash · dentro do repositório 
python scripts/skill_hub.py install --agents claude
PASSO 03
Conferir

O doctor confere a instalação e termina com a contagem de entradas verificadas e 0 problemas. Depois, em uma sessão do Claude Code, rode /agents: os lay-* aparecem na lista.

bash · dentro do repositório 
python scripts/skill_hub.py doctor
Escopos. O global (passo 02) vale em todos os seus projetos. Os mesmos 11 arquivos ficam versionados em .claude/agents/ deste repositório e valem quando o Claude Code abre este repositório. Quando os dois existem, o do projeto prevalece.
03 · COMO CHAMAR

Automático ou pelo nome

Você não precisa decorar nada. Escreva o pedido normalmente, ou nomeie o especialista.

Automático
O Claude escolhe

Ele compara seu pedido com a description de cada subagente, que traz os gatilhos Use quando e Não use para.

Exemplo: "revise a segurança do login" aciona lay-seguranca.

Explícito
Você nomeia

Quando quiser certeza do especialista, peça pelo nome:

use o subagente lay-qa para cobrir o fluxo de checkout com testes

Subagente novo não aparece? Reinicie a sessão. Os perfis são carregados no início da sessão.

05 · ORQUESTRAÇÃO

Quem decide é a conversa

A conversa principal escolhe o domínio, delega e junta as respostas. Subagentes não chamam outros subagentes.

1 · Pedido
Você descreve o que quer.
2 · Domínio
A conversa escolhe um domínio primário.
3 · HANDOFF
Delega com task, domain, context, constraints e acceptance_criteria.
4 · RESULT
O subagente devolve status, artifacts, summary e open_items.
5 · Resposta
A conversa responde em português direto.
  • Um domínio primário por pedido. Domínios independentes rodam em paralelo, em lotes de até 5.
  • Pedido ambíguo: no máximo uma pergunta de clarificação.
  • Nenhum domínio cobre o pedido: a resposta diz isso e sugere criar uma skill.
  • Ações externas ou irreversíveis (enviar, publicar, apagar) só com confirmação explícita.
06 · PROMPTS PARA COPIAR

Cole no Claude Code

Copie o bloco, cole na sessão do Claude Code e envie. Eles não dependem de nenhum dado pessoal.

PROMPT A
Instalar os subagentes

Use em um computador novo, com o Claude Code aberto na pasta onde quer o clone.

prompt · instalação 
Instale os subagentes LAY deste computador. Siga estes passos e pare se algum falhar:

1. Se o repositório ainda não existir aqui, clone com submódulos:
   git clone --recurse-submodules https://github.com/Lound-Angry-Young/LAY-Skills-Hub.git
   Entre na pasta criada.
2. Rode: python scripts/skill_hub.py install --agents claude
3. Rode: python scripts/skill_hub.py doctor e me mostre o resultado.
4. Confirme que a pasta ~/.claude/agents tem 11 arquivos lay-*.md.
5. Não rode sync --apply, reset nem nenhum comando que altere o repositório sem me perguntar antes.
6. Ao final, diga se preciso reiniciar a sessão para os subagentes aparecerem.
PROMPT B
Atualizar com confirmação

Consulta primeiro. Só aplica depois que você disser sim.

prompt · atualização 
Atualize os subagentes LAY deste computador, sem alterar nada sem minha confirmação:

1. Entre na pasta do clone do LAY-Skills-Hub.
2. Rode: python scripts/skill_hub.py sync --check e me mostre o que mudou.
3. Só se eu confirmar, rode: python scripts/skill_hub.py sync --apply
4. Depois rode: python scripts/skill_hub.py install --agents all e python scripts/skill_hub.py doctor.
5. Diga se preciso reiniciar a sessão.

07 · ATUALIZAR E REMOVER

Sem surpresas

A abertura de sessão só consulta. Aplicar é sempre um comando seu.

ATUALIZAR
Consultar, aplicar, reinstalar

Consulta: sync --check. Aplica: sync --apply, que só faz fast-forward limpo e preserva suas alterações. Depois, install --agents all.

bash · dentro do repositório 
python scripts/skill_hub.py sync --check
python scripts/skill_hub.py sync --apply
python scripts/skill_hub.py install --agents all
REMOVER
Desinstalar

Remove os subagentes lay-* que você não editou à mão. Arquivos seus, com outro nome, ficam.

bash · dentro do repositório 
python scripts/skill_hub.py uninstall
08 · PROBLEMAS COMUNS

Se algo falhar

A instalação para quando encontra algo que não pode sobrescrever. Nada é apagado por engano.

Sintoma Causa provável O que fazer
Subagente não aparece A sessão foi aberta antes da instalação. Reinicie a sessão do Claude Code e rode doctor.
Mensagem com "Colisão" Já existe um lay-*.md que não é do instalador. Renomeie ou remova o seu arquivo e rode a instalação de novo. O arquivo existente é preservado até lá.
Mensagem com "modificado" Você editou um lay-*.md à mão. Guarde sua edição com outro nome, remova o arquivo e reinstale.
Mensagem com "Fonte modificada" Há alteração rastreada no clone de uma fonte. Rode git status no clone e resolva antes de instalar.
python não encontrado Python ausente ou fora do PATH. Instale o Python 3.10+. No Windows, use py -3.
